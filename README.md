# ooru.

Every festival near you, on one free map.

ooru is a neighbourhood-first platform for festivals and small community
events: temple festivals, apartment celebrations, bhajans, cultural evenings,
local markets and makers fairs. Bengaluru first. Parties and nightlife are
out of scope, on purpose.

Free to list. Free to join. Free for visitors.

## This repo is the website

This is a plain static site, no build step. `index.html` at the root is the
whole home experience: the festival street background, the doorway opening,
the event cards, and the listing views. Styles live in the `dw2-*.css` files,
behaviour in `engine.js`, `glue.js`, `motion.js` and `decorate.js`, animation
in `gsap.min.js` and `ScrollTrigger.min.js`, artwork in the `.jpg`, `.png`
and `symbols.svg` files.

## How to change it

Edit the files, commit, and the live site updates from this repo. Listings
shown here are samples, labelled as such, until an organiser confirms them.
There are no payments in this version.

## Status

Public home page for ooru, built from the Doorway v2 face. The full app
(maps, search, organiser submissions, review queue) is being built alongside
it and will replace these sample listings with real ones as organisers
confirm them.
